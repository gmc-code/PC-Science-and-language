        What are characteristics?

        [x] Typical features or traits of an organism, such as size, shape, and colour. | Correct! Characteristics are the features used to identify organisms.
        [ ] A key with exactly two choices at each step. | Incorrect. That describes a dichotomous key.
        [ ] The name given to a newly discovered species. | Incorrect. Characteristics are features, not names.
        [ ] A table of numbered statements. | Incorrect. That describes a tabular key.

    .. multichoice::

        What is an identification key?

        [ ] A list of every species on Earth. | Incorrect. A key helps identify one organism at a time.
        [x] A series of ordered statements or questions used to identify a living or non-living thing. | Correct! Keys guide you step by step to an identification.
        [ ] A tool for measuring the size of organisms. | Incorrect. Keys use features but do not measure them.
        [ ] A drawing of an organism's habitat. | Incorrect. Keys focus on the organism's features.

    .. multichoice::

        Why do scientists use keys to identify organisms?

        [ ] Because all species look completely different. | Incorrect. Keys are most useful when species look similar.
        [ ] Because keys change an organism's features. | Incorrect. Keys only describe features.
        [x] Because shared features make identification difficult, and keys highlight subtle differences. | Correct! Keys help tell similar species apart.
        [ ] Because keys work only on non-living things. | Incorrect. Keys can identify both living and non-living things.

    .. multichoice::

        What is a dichotomous key?

        [ ] A key with more than two options at each step. | Incorrect. That describes a polytomous key.
        [ ] A key shaped like a circle. | Incorrect. That describes a circular key.
        [ ] A key presented as a table. | Incorrect. That describes a tabular key.
        [x] A key with exactly two options at each stage. | Correct! "Dichotomous" means two choices at each step.

    .. multichoice::

        What is a polytomous key?

        [x] A key with more than two options at each step. | Correct! Polytomous keys are used for complex identification tasks.
        [ ] A key with exactly two options at each step. | Incorrect. That describes a dichotomous key.
        [ ] A key that starts in the centre of a circle. | Incorrect. That describes a circular key.
        [ ] A key that only identifies plants. | Incorrect. Polytomous keys can identify any organism.

    .. multichoice::

        Which type of key uses a tree-like design?

        [ ] Tabular key | Incorrect. A tabular key is set out as a table.
        [x] Branching key | Correct! Each branch represents an identifying characteristic.
        [ ] Circular key | Incorrect. A circular key starts in the centre and moves outwards.
        [ ] Polytomous key | Incorrect. Polytomous describes the number of options, not a tree shape.

    .. multichoice::

        How does a circular key work?

        [ ] It presents questions inside a numbered table. | Incorrect. That describes a tabular key.
        [ ] It offers exactly two choices in a tree shape. | Incorrect. That describes a branching dichotomous key.
        [x] Broad traits start in the centre and lead outward to species names. | Correct! A circular key moves from the centre outwards.
        [ ] It lists species in alphabetical order. | Incorrect. Keys are organized by features, not alphabetically.

    .. multichoice::

        What is a tabular key?

        [ ] A key drawn as a tree. | Incorrect. That describes a branching key.
        [ ] A key shaped like a circle. | Incorrect. That describes a circular key.
        [ ] A key with no numbered steps. | Incorrect. Tabular keys use numbered statements.
        [x] A key presented as a table with numbered statements directing the user to the next step. | Correct! Tabular keys use a numbered table.

    .. multichoice::

        A key asks whether a leaf is serrated or not. How many options does this step have?

        [x] Two, as in a dichotomous key. | Correct! Serrated or not serrated is a two-option choice.
        [ ] Three, as in a polytomous key. | Incorrect. This step offers only two options.
        [ ] One, as in a tabular key. | Incorrect. Every step of a key offers at least two options.
        [ ] Five, as in a circular key. | Incorrect. This step offers only two options.

    .. multichoice::

        How does learning to use classification keys help us?

        [ ] It lets us change species into new forms. | Incorrect. Keys identify organisms; they do not change them.
        [x] It helps us understand an organism's role and relationships within its habitat. | Correct! Identifying species helps us understand their place in the habitat.
        [ ] It removes the need to observe organisms. | Incorrect. Keys depend on careful observation.
        [ ] It tells us the age of an organism. | Incorrect. Keys identify the type of organism, not its age.
