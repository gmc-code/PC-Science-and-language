====================================
2C Keys for Classification Key Terms
====================================

Introduction to Classification Keys
===================================

.. cloze::

    1. @@Key@@: A series of ordered statements or questions used to identify a living or non-living thing.
    2. @@Characteristics@@: Typical features, traits, or qualities of an organism like size, shape, and color.

----

Types of Classification Keys
============================

.. cloze::

    1. @@Dichotomous@@: Having only two options or choices at each stage of the identification process.
    2. @@Circular Key@@: A key structured as a circle, where broad traits start in the center and lead outward to species names.
    3. @@Branching Key@@: A tree-like key where each branch represents an identification characteristic.
    4. @@Polytomous@@: Having more than two options at each step of the key.
    5. @@Tabular Key@@: A key presented as a table with numbered statements that direct the user to subsequent steps.
