============================================================
7C Applications of Electric Circuits Key Terms
============================================================

Summary of Key Concepts 1
=========================

.. cloze::

    1. @@Sensor@@: A device that detects changes in the environment and converts them into an electrical signal.
    2. @@Proximity sensor@@: Detects the presence, absence, or distance of an object without touching it.
    3. @@Ultrasonic sensor@@: Emits high-frequency sound waves to measure the distance to obstacles in self-driving cars.
    4. @@Infrared sensor@@: Emits a beam of light to detect nearby objects in security systems and automatic taps.

----

Summary of Key Concepts 2
=========================

.. cloze::

    1. @@Thermistor@@: A temperature-sensitive resistor whose resistance changes when the temperature changes.
    2. @@Central heating@@: Uses thermistors to detect temperature changes and control heating or cooling.
    3. @@Photoresistor@@: A light-sensitive resistor whose resistance changes based on the amount of light.
    4. @@Street lights@@: Use photoresistors to turn on automatically when the environment gets dark.

----
