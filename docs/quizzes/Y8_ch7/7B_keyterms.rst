============================================================
7B Series and Parallel Circuits Key Terms
============================================================

Summary of Key Concepts 1
=========================

.. cloze::

    1. @@Closed circuit@@: A circuit with an unbroken path that electricity needs to flow.
    2. @@Conductor@@: A material that allows electric current to flow through it easily.
    3. @@Power supply@@: A device like a battery that provides the voltage and current for a circuit.
    4. @@Load@@: A component that transforms electrical energy into light or heat.

----

Summary of Key Concepts 2
=========================

.. cloze::

    1. @@Voltage@@: The electrical push that moves energy, measured in volts using a voltmeter.
    2. @@Current@@: The flow of electric charge, measured in amps using an ammeter.
    3. @@Resistance@@: Opposes or slows down the flow of electric current in a circuit.
    4. @@Open switch@@: Breaks the circuit loop and causes all electrical current to stop.
    5. @@Multimeter@@: A tool that can measure voltage, current, and resistance.

----

.. cloze::
