============================================================
7A Electric Circuits Key Terms
============================================================

Summary of Key Concepts 1
=========================

.. cloze::

    1. @@Series circuit@@: A circuit with a single pathway for electric current to flow through all components.
    2. @@Parallel circuit@@: A circuit that branches into multiple pathways so each component has its own separate loop.
    3. @@Current@@: The flow of electric charge, which is the same everywhere in a series circuit.
    4. @@Voltage@@: The electrical push supplied by a battery, which is shared between components in a series circuit.

----

Summary of Key Concepts 2
=========================

.. cloze::

    1. @@Switch@@: Turning this off in a series circuit stops current flowing to all light bulbs.
    2. @@Circuit breaker@@: A safety device that automatically shuts off power during a short circuit.
    3. @@Short circuit@@: An unintended low-resistance path that causes excessive electrical current.
    4. @@Parallel circuits@@: Used in modern houses so appliances can operate independently of each other.

----
