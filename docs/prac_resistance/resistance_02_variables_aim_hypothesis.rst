Question 2: Variables
------------------------------------------------

.. admonition:: Question 2
    :class: important

    | a. Complete the table by providing one variable from the investigation for each classification.
    | b. Using your identified controlled variable for part a, justify why it needs to be controlled.

.. admonition:: Key ideas
    :class: note

    * **Independent variable (IV)**: the one variable you deliberately **change**.
    * **Dependent variable (DV)**: the variable you **measure or calculate** to see the effect.
    * **Controlled variables**: everything you keep the **same** so that the test is fair.
    * A controlled variable must be kept the same so that **only the IV** can cause a change in the DV.

   :widths: 25 75
   :header-rows: 1

   * - independent
     - The number of light globes connected in series (1, 2 or 3)
   * - dependent
     - The resistance of the circuit (Ω), calculated from the voltage and the current
   * - controlled
     - The voltage setting on the power pack (also: type of globe, length and type of leads)

Question 3: Aim
------------------------------------------------

.. admonition:: Question 3 (1 mark)
    :class: important

    Construct an aim for the research question provided.

.. admonition:: Key ideas
    :class: note

    * An aim starts with **To investigate** or **To determine**.
    * An aim names both the **independent variable** and the **dependent variable**.
    * An aim does **not** predict the result.

.. admonition:: Sentence starter
    :class: tip

    To investigate how *(the IV)* affects *(the DV)*.

Question 4: Hypothesis
------------------------------------------------

.. admonition:: Question 4
    :class: important

    Using the information given throughout this document, construct a hypothesis for this experiment.
    Give a reason for your response.

.. admonition:: Key ideas
    :class: note

    * A hypothesis is a **testable prediction** about how the IV will affect the DV.
    * Use the pattern **If** *(change in the IV)* **then** *(effect on the DV)* **because** *(scientific reason)*.
    * The reason must come from the **background information**: resistance is how difficult it is for electrons to flow.

.. admonition:: Watch out
    :class: warning

    One mark is for the prediction and one mark is for the reason. A hypothesis without **because** can only earn one mark.
