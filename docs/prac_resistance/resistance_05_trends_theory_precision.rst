Question 11: Linking results to theory
------------------------------------------------

.. admonition:: Question 11 (2 marks)
    :class: important

    Explain how the results and observations connect to the scientific theory for electricity and the relationship of Ohm's law.

.. admonition:: Key ideas
    :class: note

    * **Ohm's law**: R = V ÷ I.
    * If the **voltage stays the same** and the **current gets smaller**, the **resistance must be larger**.
    * In a **series** circuit there is only one path, so the electrons must pass through **every** globe.
    * An **observation** is something you saw, e.g. the globes glowed more dimly as more were added.

Question 12: Precision
------------------------------------------------

.. admonition:: Question 12 (2 marks)
    :class: important

    Using your understanding of precision, explain why it is impossible to draw any conclusions on the precision
    of the data in terms of repeatability.

.. admonition:: Key ideas
    :class: note

    * **Precision** is how **close together** repeated measurements are.
    * **Repeatability** means getting similar results when the **same** experiment is repeated in the same way.
    * To judge precision you need **more than one trial** for each condition, so the values can be compared.
    * The results table has only **one** reading for each number of globes.

.. admonition:: Watch out
    :class: warning

    Do not confuse precision with **accuracy**. Accuracy is how close a result is to the **true value**.
