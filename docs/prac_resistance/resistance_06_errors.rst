================================================
Step 6. Random and Systematic Errors
================================================

Part C: Analysis and Evaluation

.. admonition:: Key ideas
    :class: note

    * A **random error** changes each measurement by a **different, unpredictable** amount. Results may be too high or too low.
    * Random errors reduce **precision**. They are reduced by **repeating trials and averaging**.
    * A **systematic error** shifts every measurement by the **same amount in the same direction**.
    * Systematic errors reduce **accuracy**. Repeating trials does **not** remove them.

Question 13a: Random error
------------------------------------------------

.. admonition:: Question 13a (2 marks)
    :class: important

    Identify one random error that may have affected your data.
    Explain how this error would impact the final calculated value for resistance.

.. admonition:: Watch out
    :class: warning

    One mark is for **naming** the error and one mark is for its **effect on the calculated resistance**.
    Remember R = V ÷ I: a current reading that is **too high** gives a resistance that is **too low**.

Fill in the gaps
~~~~~~~~~~~~~~~~~~~~~~

.. cloze::
    :instructions: Drag each word from the word bank into the correct gap. Each word is used once.

    1. One random error is that the reading on the ammeter @@fluctuated@@ while it was being read.
    2. This means the recorded current could be slightly too high or too low, in an @@unpredictable@@ way.
    3. Resistance is calculated by @@dividing@@ the voltage by the current.
    4. If the recorded current was too high, the calculated resistance would be too @@low@@.
    5. If the recorded current was too low, the calculated resistance would be too @@high@@.
    6. This error reduces the @@precision@@ of the calculated resistance.

Fill in the gaps
~~~~~~~~~~~~~~~~~~~~~~

    1. Repeat the experiment at least @@three@@ times for each number of globes.
    2. Calculate the @@average@@ resistance for each number of globes.
    3. Averaging reduces the effect of @@random@@ errors because readings that are too high and too low tend to @@cancel@@ out.

Question 13c: Systematic error
------------------------------------------------

.. admonition:: Question 13c (2 marks)
    :class: important

    Identify one systematic error that may have affected your data.
    Explain how this error would impact the final calculated value for resistance.

.. admonition:: Watch out
    :class: warning

    A systematic error affects **every** result in the **same direction**. State the direction:
    are all of the calculated resistances too high, or all too low?

Fill in the gaps
~~~~~~~~~~~~~~~~~~~~~~

.. cloze::
    :instructions: Drag each word from the word bank into the correct gap. Each word is used once.

    1. One systematic error is a @@zero@@ error, where the ammeter does not read 0 A when no current is flowing.
    2. If the ammeter reads slightly too high, @@every@@ current reading is too high by the same amount.
    3. Because resistance equals voltage divided by current, every calculated resistance would be too @@low@@.
    4. This error reduces the @@accuracy@@ of the results.
    5. Repeating trials would not fix this error. The ammeter must be @@calibrated@@ so that it reads zero before the experiment.
