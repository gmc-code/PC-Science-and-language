================================================
12–14. Data Quality, Errors and Improvements
================================================

12. Accuracy, precision, reliability and validity
--------------------------------------------------

.. list-table::
   :widths: 18 40 42
   :header-rows: 1

   * - Term
     - Meaning
     - How to check or improve it
   * - Accuracy
     - How close a result is to the **true (accepted) value**.
     - Compare your average with the true value. A small difference = high accuracy.
   * - Precision
     - How close the **repeated results are to each other**.
     - Look at the **range** (largest − smallest). A small range = high precision.
   * - Reliability
     - Getting **similar results** each time the experiment is repeated.
     - Do more repeat trials and calculate an average.
   * - Validity
     - Whether the experiment is a **fair test** of the aim.
     - Change only the IV and control all other variables.

.. admonition:: Using the data
    :class: hint

    * **Accuracy (15 cm):** true value = 90 cm, experimental average = 90.3 cm. The difference is only 0.3 cm, so the result has **very high accuracy**.
    * **Accuracy (20 cm):** true value = 120 cm, average = 117.0 cm. The difference is 3.0 cm, so it is still fairly accurate, but less accurate than at 15 cm.
    * **Precision (15 cm):** trials were 89, 92 and 90 cm. Range = 92 − 89 = 3 cm. The results are close together, so precision is **high**.
    * **Precision (20 cm):** trials were 118, 124 and 109 cm. Range = 124 − 109 = 15 cm, so these results are **less precise**. The 109 cm trial is a possible outlier.

.. admonition:: Watch out
    :class: warning

    **Accuracy** compares to the **true value**. **Precision** compares the trials to **each other**. Don't mix them up!
    Always **quote the numbers** (e.g. "a range of only 3 cm") when asked to refer to data.

13. Errors
------------------------------------------------

.. list-table::
   :widths: 18 47 35
   :header-rows: 1

   * - Type of error
     - What it is
     - How to reduce it
   * - Random error
     - Unpredictable changes that make results **scatter** above and below the true value (e.g. the marble released slightly differently each time). Affects **precision**.
     - Do **more repeat trials** and calculate an **average**.
   * - Systematic error
     - An error that shifts **every** result in the **same direction** (e.g. always measuring from the books instead of the end of the ramp, which adds extra distance every time). Affects **accuracy**.
     - Check the method and equipment; measure from the correct point. Averaging does NOT fix it.
   * - Parallax error
     - Reading a scale from an **angle** instead of straight on, so the reading looks **bigger or smaller** than it really is.
     - Put your eye **level with / directly above** the mark and read straight on.
   * - Mistakes (human error)
     - Errors like misreading, writing the wrong number or bumping the ramp.
     - Take care, double-check readings, and repeat the trial.

.. admonition:: Example scenario
    :class: hint

    A student measures the **ramp height** by looking down at the ruler from above instead of with their eye level with the top of the ramp → **parallax error**.
    The ramp could be set higher or lower than intended, so the marble would roll a different distance from the one expected for that height.

    **Improvement:** crouch down so your eye is level with the top of the ramp and read the ruler straight on.

14. Improving the investigation
------------------------------------------------

.. admonition:: Key ideas
    :class: note

    * **More repeat trials** (e.g. 5 per height) and averaging reduce the effect of random errors and make results more **reliable**.
    * **Test more ramp heights** (e.g. every 2.5 cm) to show the trend more clearly on the graph.
    * **Mark** the release point and end of the ramp with masking tape so every trial is the same.
    * Use better equipment, e.g. a measuring tape taped to the floor, or **video** the marble to see exactly where it stops.
    * **Keep controlled variables the same.** Changing them (e.g. a different marble at each height) adds a new variable and makes results less comparable.

.. admonition:: Example scenario
    :class: hint

    **Student A:** "Hold a ruler across the ramp and lift it away to release the marble, so it starts the same way every time."
    → **improves quality**, because it reduces random error from uneven releases, so the trials are closer together (more precise).

    **Student B:** "Just do one trial at each height to save time."
    → **makes it worse**, because with one trial an error or outlier can't be spotted or averaged out, so the results are less reliable.
