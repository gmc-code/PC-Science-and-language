    .. multichoice::

        What does electricity need in order to flow?

        [x] A closed circuit with an unbroken path. | Correct! Current can only flow when the circuit loop is complete.
        [ ] An open switch somewhere in the circuit. | Incorrect. An open switch breaks the loop and stops the current.
        [ ] A circuit made from insulators. | Incorrect. Insulators do not allow current to flow easily.
        [ ] A gap in the wires. | Incorrect. Any gap breaks the circuit and stops the flow.

    .. multichoice::

        What is a conductor?

        [ ] A material that stops electric current from flowing. | Incorrect. That describes an insulator.
        [x] A material that allows electric current to flow through it easily. | Correct! Conductors, like copper, let current flow easily.
        [ ] A device that measures voltage. | Incorrect. Voltage is measured with a voltmeter.
        [ ] A component that turns electrical energy into light. | Incorrect. That describes a load, such as a light bulb.

    .. multichoice::

        What does the simplest electric circuit contain?

        [ ] A voltmeter, an ammeter, and a multimeter. | Incorrect. These are measuring tools, not required parts of a circuit.
        [ ] Only a battery. | Incorrect. A battery alone cannot form a complete circuit.
        [x] A power supply, connecting wires, and a load. | Correct! These three parts make the simplest working circuit.
        [ ] A switch and a resistor only. | Incorrect. Without a power supply, no current can flow.

    .. multichoice::

        What is voltage measured in, and with which device?

        [ ] Amps, using an ammeter. | Incorrect. Amps and ammeters are used for current.
        [ ] Ohms, using a thermometer. | Incorrect. A thermometer measures temperature.
        [ ] Watts, using a switch. | Incorrect. A switch opens and closes a circuit; it does not measure anything.
        [x] Volts, using a voltmeter. | Correct! Voltage is measured in volts with a voltmeter.

    .. multichoice::

        What is current measured in, and with which device?

        [x] Amps, using an ammeter. | Correct! Current is the flow of charge, measured in amps with an ammeter.
        [ ] Volts, using a voltmeter. | Incorrect. Volts and voltmeters are used for voltage.
        [ ] Metres, using a ruler. | Incorrect. A ruler measures length, not electric current.
        [ ] Degrees, using a thermistor. | Incorrect. A thermistor is a temperature-sensitive resistor.

    .. multichoice::

        What does resistance do in a circuit?

        [ ] It increases the flow of current. | Incorrect. Resistance works against the flow of current.
        [x] It opposes or slows down the flow of electric current. | Correct! Resistance makes it harder for current to flow.
        [ ] It provides the push that moves energy. | Incorrect. The push is provided by voltage.
        [ ] It stores electrical energy like a battery. | Incorrect. Resistance does not store energy.

    .. multichoice::

        What happens when a switch is opened?

        [ ] The current flows faster. | Incorrect. An open switch stops the current completely.
        [ ] The voltage of the battery doubles. | Incorrect. Opening a switch does not change the battery's voltage.
        [x] The circuit loop is broken and all current stops. | Correct! An open switch creates a gap, so no current can flow.
        [ ] The circuit becomes a parallel circuit. | Incorrect. Opening a switch does not change the type of circuit.

    .. multichoice::

        How is a voltmeter connected in a circuit?

        [x] In parallel with the component. | Correct! A voltmeter is connected in parallel to measure voltage.
        [ ] In series with the component. | Incorrect. An ammeter is connected in series.
        [ ] It replaces the battery. | Incorrect. A voltmeter measures voltage; it does not supply it.
        [ ] It is not connected to the circuit at all. | Incorrect. It must be connected to take a reading.

    .. multichoice::

        How is an ammeter connected in a circuit?

        [ ] In parallel with the component. | Incorrect. A voltmeter is connected in parallel.
        [ ] Across the terminals of the battery only. | Incorrect. An ammeter must be part of the current's pathway.
        [ ] Outside the circuit loop. | Incorrect. An ammeter must be in the loop to measure the current.
        [x] In series with the component. | Correct! An ammeter is connected in series so the current flows through it.

    .. multichoice::

        Which tool can measure voltage, current, and resistance?

        [ ] Ammeter | Incorrect. An ammeter measures only current.
        [x] Multimeter | Correct! A multimeter can measure voltage, current, and resistance.
        [ ] Voltmeter | Incorrect. A voltmeter measures only voltage.
        [ ] Resistor | Incorrect. A resistor is a component that reduces current flow, not a measuring tool.
