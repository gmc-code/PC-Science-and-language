        What is a sensor?

        [x] A device that detects changes in the environment and converts them into an electrical signal. | Correct! Sensors turn changes like light, heat, or distance into electrical signals.
        [ ] A device that stores electrical energy. | Incorrect. Batteries store energy; sensors detect changes.
        [ ] A safety device that cuts power during a short circuit. | Incorrect. That describes a circuit breaker.
        [ ] A wire that connects components together. | Incorrect. Connecting wires carry current but do not detect changes.

    .. multichoice::

        What can a proximity sensor detect?

        [ ] Only the temperature of an object. | Incorrect. Temperature is detected by a thermistor.
        [ ] Only the colour of an object. | Incorrect. Proximity sensors detect presence and distance, not colour.
        [x] The presence, absence, or distance of an object without touching it. | Correct! Proximity sensors work without physical contact.
        [ ] The voltage of a battery. | Incorrect. Voltage is measured with a voltmeter.

    .. multichoice::

        How do ultrasonic sensors in self-driving cars measure distance to obstacles?

        [ ] By emitting a beam of light. | Incorrect. Infrared sensors emit a beam of light.
        [x] By emitting high-frequency sound waves. | Correct! Ultrasonic sensors use sound waves that bounce back from obstacles.
        [ ] By measuring changes in temperature. | Incorrect. Temperature changes are detected by thermistors.
        [ ] By touching the obstacle. | Incorrect. Ultrasonic sensors measure distance without contact.

    .. multichoice::

        How does an infrared sensor detect nearby objects?

        [ ] By emitting high-frequency sound waves. | Incorrect. Ultrasonic sensors emit sound waves.
        [ ] By changing its resistance with temperature. | Incorrect. That describes a thermistor.
        [ ] By measuring the current in a circuit. | Incorrect. Current is measured with an ammeter.
        [x] By emitting a beam of light. | Correct! Infrared sensors use a light beam to detect objects.

    .. multichoice::

        What is a thermistor?

        [x] A temperature-sensitive resistor. | Correct! A thermistor's resistance changes when the temperature changes.
        [ ] A light-sensitive resistor. | Incorrect. A light-sensitive resistor is a photoresistor.
        [ ] A sensor that emits sound waves. | Incorrect. That describes an ultrasonic sensor.
        [ ] A device that measures current. | Incorrect. Current is measured with an ammeter.

    .. multichoice::

        Which component do central heating systems use to detect temperature changes?

        [ ] Photoresistor | Incorrect. A photoresistor responds to light, not temperature.
        [ ] Ultrasonic sensor | Incorrect. Ultrasonic sensors measure distance using sound waves.
        [x] Thermistor | Correct! Thermistors detect temperature changes to control heating or cooling.
        [ ] Infrared sensor | Incorrect. Infrared sensors detect nearby objects using a beam of light.

    .. multichoice::

        What is a photoresistor?

        [ ] A temperature-sensitive resistor. | Incorrect. A temperature-sensitive resistor is a thermistor.
        [x] A light-sensitive resistor whose resistance changes with the amount of light. | Correct! Photoresistors respond to changes in light.
        [ ] A sensor that emits a beam of light. | Incorrect. That describes an infrared sensor.
        [ ] A safety switch in household circuits. | Incorrect. That describes a circuit breaker.

    .. multichoice::

        How do street lights turn on automatically when it gets dark?

        [ ] A thermistor detects a drop in temperature. | Incorrect. Street lights respond to light levels, not temperature.
        [ ] An ultrasonic sensor detects passing cars. | Incorrect. Ultrasonic sensors measure distance, not light levels.
        [ ] A circuit breaker switches them on. | Incorrect. Circuit breakers cut power during a short circuit.
        [x] A photoresistor detects the drop in light. | Correct! The photoresistor's resistance changes in the dark, switching the light on.

    .. multichoice::

        Which type of sensor is used in automatic taps?

        [x] Infrared sensor | Correct! Infrared sensors detect hands near the tap using a beam of light.
        [ ] Thermistor | Incorrect. Thermistors detect temperature changes.
        [ ] Photoresistor | Incorrect. Photoresistors are used in automatic street lights.
        [ ] Ultrasonic sensor | Incorrect. Ultrasonic sensors are used to measure obstacle distances in self-driving cars.

    .. multichoice::

        What happens to a thermistor when the temperature changes?

        [ ] It emits a beam of light. | Incorrect. Infrared sensors emit light beams.
        [ ] It stops all current in the circuit. | Incorrect. That is what an open switch does.
        [x] Its resistance changes. | Correct! A thermistor's resistance changes with temperature.
        [ ] It produces sound waves. | Incorrect. Ultrasonic sensors produce sound waves.
