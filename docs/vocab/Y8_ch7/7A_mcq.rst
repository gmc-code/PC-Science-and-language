    .. multichoice::

        What is a series circuit?

        [x] A circuit with a single pathway for current to flow through all components. | Correct! A series circuit has only one path for the current.
        [ ] A circuit that branches into multiple separate pathways. | Incorrect. That describes a parallel circuit.
        [ ] A safety device that turns off power during a short circuit. | Incorrect. That describes a circuit breaker.
        [ ] An unintended low-resistance path for current. | Incorrect. That describes a short circuit.

    .. multichoice::

        What is a parallel circuit?

        [ ] A circuit with only one continuous loop. | Incorrect. A single continuous loop is a series circuit.
        [x] A circuit that branches into multiple pathways so each component has its own loop. | Correct! Each branch of a parallel circuit is its own separate loop.
        [ ] A circuit with no power supply. | Incorrect. Every working circuit needs a power supply.
        [ ] A circuit where the current stops at the first bulb. | Incorrect. Current flows through all branches of a parallel circuit.

    .. multichoice::

        What happens when you turn off a switch in a series circuit?

        [ ] Only the bulb nearest the switch goes out. | Incorrect. With only one pathway, all bulbs are affected.
        [ ] The other bulbs get brighter. | Incorrect. No current flows, so no bulbs light up.
        [x] Current stops flowing to all the light bulbs. | Correct! Opening the switch breaks the single pathway, so every bulb goes out.
        [ ] The voltage of the battery increases. | Incorrect. The switch does not change the battery's voltage.

    .. multichoice::

        In a parallel circuit, what happens when one branch is switched off?

        [x] Electricity keeps flowing through the other branches. | Correct! Each branch has its own loop, so the others keep working.
        [ ] All the other branches stop working too. | Incorrect. That happens in a series circuit, not a parallel circuit.
        [ ] The battery stops supplying voltage. | Incorrect. The battery still supplies the other branches.
        [ ] A short circuit is created. | Incorrect. Switching off a branch does not create a short circuit.

    .. multichoice::

        How does current behave in a series circuit?

        [ ] It doubles at each light bulb. | Incorrect. Current does not increase as it passes through components.
        [ ] It drops to zero after the first component. | Incorrect. Current continues through the whole loop.
        [ ] It splits between different branches. | Incorrect. Splitting between branches happens in a parallel circuit.
        [x] It is the same everywhere in the circuit. | Correct! In a series circuit the current is the same at every point.

    .. multichoice::

        What happens to the total voltage in a series circuit?

        [x] It is shared between the components. | Correct! In a series circuit the battery's voltage is divided among the components.
        [ ] Each component receives the full battery voltage. | Incorrect. That is true for each branch of a parallel circuit.
        [ ] It increases with every component added. | Incorrect. Adding components does not increase the battery's voltage.
        [ ] It is always zero. | Incorrect. The battery supplies voltage to push the current.

    .. multichoice::

        In a parallel circuit, how does the voltage across each branch compare to the battery voltage?

        [ ] It is half the battery voltage. | Incorrect. Voltage is not halved across parallel branches.
        [x] It is equal to the voltage supplied by the battery. | Correct! Each parallel branch receives the full battery voltage.
        [ ] It is double the battery voltage. | Incorrect. A branch cannot receive more voltage than the battery supplies.
        [ ] It is shared equally between all branches. | Incorrect. Sharing voltage happens in a series circuit.

    .. multichoice::

        Why do modern houses use parallel circuits?

        [ ] So that all appliances turn off together. | Incorrect. Parallel circuits let appliances work separately.
        [ ] So that less wire is needed. | Incorrect. Parallel circuits are chosen for independent operation, not to save wire.
        [x] So that appliances can operate independently of each other. | Correct! Each appliance has its own branch and can be switched on or off separately.
        [ ] So that the current is the same everywhere. | Incorrect. Equal current everywhere is a feature of series circuits.

    .. multichoice::

        What is the purpose of a circuit breaker?

        [ ] To measure the current in a circuit. | Incorrect. Current is measured with an ammeter.
        [ ] To increase the voltage in a household circuit. | Incorrect. A circuit breaker does not increase voltage.
        [ ] To split a circuit into parallel branches. | Incorrect. Branches are created by the circuit's wiring.
        [x] To automatically shut off power during a short circuit. | Correct! Circuit breakers cut the power to prevent fires and electric shock.

    .. multichoice::

        What is a short circuit?

        [x] An unintended low-resistance path that causes excessive current. | Correct! A short circuit lets too much current flow, which can cause fires.
        [ ] A circuit with only one light bulb. | Incorrect. The number of bulbs does not make a short circuit.
        [ ] A circuit that has been switched off. | Incorrect. A switched-off circuit has no current flowing.
        [ ] A circuit with very short wires. | Incorrect. A short circuit is about an unintended path, not wire length.
