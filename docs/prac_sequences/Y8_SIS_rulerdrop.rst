=================================
Y8 SIS ruler drop prac sequence
=================================

**Drag** a picture into a box, or **tap** a picture and then
tap a box.


.. imagesequence:: Y8 SIS ruler drop method
   :answer-key:
   :captions: slot
   :fixed: 1, 8
   :feedback: count
   :arrows: right
   :columns: 2
   :fullscreen-columns: 4
   :tray-columns: 4

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step1.png

      Hold the ruler with 0 cm level with the catcher's finger and thumb, 3 cm apart

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step2.png

      Drop the ruler without warning; the catcher grabs it

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step3.png

      Read where the ruler was caught in cm

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step4.png

      Do 3 trials and record each result

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step5.png

      Work out the average of the 3 trials

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step6.png

      Repeat while asking the catcher questions

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step7.png

      Repeat while waving a hand next to the ruler

   .. step:: images/Y8_SIS_rulerdrop/rulerdrop_Step8.png

      Repeat with a new catcher, dropping at random
