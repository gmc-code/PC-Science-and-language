====================================================
7C: Applications of Electric Circuits
====================================================

Summary of Key Concepts
----------------------------------------

* A sensor is a device that detects changes in the environment and converts them into an electrical signal.
* Proximity sensors can detect the presence, absence, or distance of an object without touching it.
* Ultrasonic sensors emit high-frequency sound waves to measure the distance to obstacles in self-driving cars.
* Infrared sensors emit a beam of light to detect nearby objects in security systems and automatic taps.
* A thermistor is a temperature-sensitive resistor whose resistance changes when the temperature changes.
* Central heating systems use thermistors to detect temperature changes and control heating or cooling.
* A photoresistor is a light-sensitive resistor whose resistance changes based on the amount of light.
* Street lights use photoresistors to turn the light on automatically when the environment gets dark.
