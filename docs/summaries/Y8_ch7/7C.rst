====================================================
7C: Applications of Electric Circuits
====================================================

Summary of Key Concepts
----------------------------------------

* A sensor is a device that detects changes in the environment and converts them into an electrical signal.
* Proximity sensors can detect the presence, absence, or distance of an object without touching it.
* Ultrasonic sensors send out high-frequency sound waves and time the echo to measure the distance to obstacles, for example in self-driving cars.
* Some infrared sensors send out an invisible infrared beam and detect it reflecting off nearby objects, as in automatic taps.
* Security systems use passive infrared sensors, which detect the infrared given off by body heat.
* A thermistor is a temperature-sensitive resistor whose resistance changes when the temperature changes.
* Central heating systems use thermistors to detect temperature changes and control heating or cooling.
* A photoresistor is a light-sensitive resistor whose resistance rises as the light gets dimmer.
* Street lights use photoresistors to turn the light on automatically when the environment gets dark.
* An electric circuit is a complete pathway for electric current.

* **Key Terms:**

  * **Sensor**: A device that turns changes into electrical signals.
  * **Thermistor**: A temperature-sensitive resistor.
  * **Photoresistor**: A light-sensitive resistor.
  * **Infrared**: Invisible light given off by warm objects.
