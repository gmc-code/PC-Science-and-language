====================================================
7C: Applications of Electric Circuits
====================================================

Summary of Key Concepts
----------------------------------------

* Sensors detect changes in the environment.
* Sensors turn these changes into electrical signals.
* Proximity sensors detect objects and their distance without touching them.
* Ultrasonic sensors send out high-frequency sound and time the echo.
* Self-driving cars use ultrasonic sensors to measure distance.
* Some infrared sensors send out an invisible infrared beam.
* Automatic taps detect hands that reflect this beam.
* Security systems detect the infrared given off by body heat.
* A thermistor's resistance changes with temperature.
* Central heating uses thermistors to control temperature.
* A photoresistor's resistance rises in the dark.
* Photoresistors switch street lights on automatically when it gets dark.
* An electric circuit is a complete pathway for electric current.

* **Key Terms:**

  * **Sensor**: A device that turns changes into electrical signals.
  * **Thermistor**: A temperature-sensitive resistor.
  * **Photoresistor**: A light-sensitive resistor.
  * **Infrared**: Invisible light given off by warm objects.
