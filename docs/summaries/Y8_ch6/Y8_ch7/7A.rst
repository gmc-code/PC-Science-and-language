====================================
7A: Electric Circuits
====================================

Summary of Key Concepts
----------------------------------------

* A series circuit has a single pathway for electric current to flow through all components.
* A parallel circuit branches into multiple pathways so each component has its own separate loop.
* Turning off a switch in a series circuit stops current flowing to all light bulbs.
* In a parallel circuit turning off one branch allows electricity to keep flowing through the other branches.
* The current is the same everywhere in a series circuit but the total voltage is shared between components.
* In a parallel circuit the voltage drop across each branch is equal to the voltage supplied by the battery.
* Modern houses use parallel circuits so that household appliances can operate independently of each other.
* Circuit breakers automatically shut off electrical power during a short circuit to prevent fires and electric shock.
