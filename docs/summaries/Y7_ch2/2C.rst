===========================
2C Keys for Classification
===========================

Introduction to Classification Keys
====================================================================

* Scientists organize living things by looking closely at their physical characteristics, such as size, shape, color, and body patterns.
* Shared features can make identification difficult, so scientists rely on structured tools called keys to highlight subtle differences between species.
* An identification key consists of a specific series of statements or questions used to identify living or non-living things.
* Learning to identify species using classification keys helps us understand an organism's unique role and relationships within its habitat.

* **Key Terms:**

  * **Characteristics**: Typical features, traits, or qualities of an organism like size, shape, and color.
  * **Key**: A series of ordered statements or questions used to identify a living or non-living thing.


.. cloze::

   1. Scientists identify living things by looking at specific @@characteristics@@ like size, shape, and @@color@@.
   2. Using an identification @@key@@ helps scientists tell similar @@species@@ apart.
   3. A key relies on a series of @@statements@@ to help identify an @@organism@@.

Types of Classification Keys
==================================

* Dichotomous keys guide the user through choices where each stage presents exactly two options, such as deciding if a leaf is serrated or not.
* Polytomous keys provide more than two options at each step and are often used for complex identification tasks.
* A branching key uses a tree-like design to guide users down specific pathways based on organism traits.
* Other visual formats include circular keys, which start at the center and move outwards, and tabular keys, which present questions inside a numbered table.

* **Key Terms:**

  * **Dichotomous**: Having only two options or choices at each stage of the identification process.
  * **Polytomous**: Having more than two options at each step of the key.
  * **Branching Key**: A tree-like key where each branch represents an identification characteristic.
  * **Circular Key**: A key structured as a circle, where broad traits start in the center and lead outward to species names.
  * **Tabular Key**: A key presented as a table with numbered statements that direct the user to subsequent steps.
