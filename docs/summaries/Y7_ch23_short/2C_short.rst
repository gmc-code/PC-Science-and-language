===========================
2C Keys for Classification
===========================

Introduction to Classification Keys
====================================================================

* Scientists look closely at physical characteristics.
* Characteristics include size, shape, color and patterns.
* Shared features can make identification difficult.
* Keys highlight subtle differences between species.
* A key is a series of statements.
* Keys identify living or non-living things.
* Keys help us understand an organism's role.

* **Key Terms:**

  * **Characteristics**: Features of an organism like size and shape.
  * **Key**: Ordered statements or questions used for identification.

   1. Scientists look at @@characteristics@@ like size and @@color@@.
   2. An identification @@key@@ tells similar @@species@@ apart.
   3. A key uses a series of @@statements@@.
   4. Keys help scientists identify an @@organism@@.

Types of Classification Keys
==================================

* Dichotomous keys give exactly two options each step.
* For example, is the leaf serrated or not?
* Polytomous keys give more than two options.
* Polytomous keys suit complex identification tasks.
* Branching keys use a tree-like design.
* Circular keys start at the center, moving outwards.
* Tabular keys present questions in a numbered table.

* **Key Terms:**

  * **Dichotomous**: Having only two options at each stage.
  * **Polytomous**: Having more than two options each step.
  * **Branching Key**: A tree-like key where branches show characteristics.
  * **Circular Key**: A round key leading outward from the center.
  * **Tabular Key**: A table of numbered statements directing users.
